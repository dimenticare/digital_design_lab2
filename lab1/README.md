# FPGA 七段数码管显示与存储器控制系统
## 项目简介

本项目基于 Xilinx FPGA，使用 Verilog HDL 实现 Memory 数据读取与八位七段数码管显示。设计中使用 Memory 保存 32-bit 数据，通过地址控制依次读取数据，并将读取结果转换为十六进制显示在八位共阳极七段数码管上。同时加入板载按键控制，实现数据显示的暂停、加速和减速。

## 主要任务

* **Memory (`mem.v`)**
  设计 32-bit 数据存储与读取逻辑，根据地址输出对应数据，为后续显示提供数据源。

* **Control (`control.v`)**
  设计地址更新与时序控制逻辑，实现 Memory 数据的自动顺序读取，并支持 **Pause / Speed Up / Speed Down** 三种显示控制。

* **Key Debounce (`KeyDebounce.v`)**
  对板载机械按键进行消抖处理，为暂停和调速功能提供稳定的控制信号。

* **Seven-Segment Display (`Seven Seg.v`)**
  将 32-bit 数据拆分为 8 个十六进制数，完成 `0~F` 七段译码，并通过动态扫描驱动八位共阳极数码管。

* **Top Module (`top.v`)**
  完成 Memory、Control、KeyDebounce 和 Seven-Segment Display 各模块的接口连接与顶层集成。

## 遇到的问题与解决方法

### 1. 八位数码管无法直接同时显示不同数字

八位数码管共享部分显示信号，无法简单地为每一位持续输出不同的七段编码。

采用**动态扫描**方式，通过计数器快速切换当前有效的 Digit，同时切换对应的七段编码，使八位数据显示保持稳定。

### 2. 共阳极数码管显示逻辑与普通逻辑相反

Xilinx 开发板使用 **Common-Anode** 数码管，Segment 为低电平时 LED 点亮。

根据开发板电路重新设计七段译码逻辑，使用 **Active-Low** 输出正确控制各个 Segment。

### 3. 机械按键出现重复触发

直接使用板载按键控制暂停和速度时，机械抖动可能导致一次按键被 FPGA 识别为多次操作。

设计 `KeyDebounce.v` 对按键信号进行稳定性检测，只向控制模块输出有效的按键操作。

### 4. 数据显示速度需要动态调整

固定的数据更新周期无法实现加速和减速操作。

在 `control.v` 中设计可调计数逻辑，通过改变地址更新周期实现显示速度调整，并支持暂停当前数据更新。

## 项目结果

* `mem.v`：完成 **32-bit Memory 数据存储与地址读取**
* `control.v`：实现 **自动读取、暂停、加速和减速控制**
* `KeyDebounce.v`：实现 **板载机械按键消抖**
* `Seven Seg.v`：实现 **32-bit 数据的八位十六进制动态显示**
* `top.v`：完成各 RTL 模块的 **顶层集成**
* 最终在 **Xilinx FPGA** 上完成系统运行与功能验证
